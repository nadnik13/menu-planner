# 🍽 Меню-планер на месяц (Flutter + Riverpod)

Приложение для планирования питания: создавайте рецепты, добавляйте их в календарь и формируйте список покупок на неделю.

---

## 🚀 Возможности

- Добавление и удаление рецептов
- Планирование рецептов на конкретные даты
- Отображение плана питания на неделю
- Управление состоянием с помощью Riverpod (`StateNotifierProvider`)
- Удобный и адаптивный интерфейс
- (в разработке) Генерация списка покупок на основе плана
- (в разработке) Локальное хранение данных через Hive

---

## 🧠 Стек технологий

- Flutter 3.x
- Riverpod 2.x
- Dart
- Material Design
- (в будущем) Hive для локального хранилища
- (в будущем) TableCalendar

## 🔧 Установка и запуск

1. Клонируй репозиторий:

```bash
git clone https://github.com/your-username/menu-planner.git
cd menu-planner
Установи зависимости:
flutter pub get
Запусти проект:
flutter run
```

# 🍽 Меню-планер на месяц (Flutter + Riverpod)

Приложение для планирования питания и управления заготовками блюд. Создано для тех, кто любит готовить впрок и хочет эффективно управлять своими запасами готовой еды.

## 🎯 Для кого это приложение?

Это приложение создано для людей, которые:
- Готовят впрок и делают заготовки
- Хотят эффективно планировать питание на недели вперед
- Следят за количеством порций в своих заготовках
- Планируют меню с учетом уже имеющихся запасов

## 💡 Как это работает?

### 1. Создание шаблонов блюд
- Создавайте шаблоны для часто готовящихся блюд, любимых продуктов
- Указывайте оптимальное количество порций для вас

### 2. Управление заготовками
- Отмечайте, сколько порций вы приготовили
- Отслеживайте статус заготовок (запланировано, в процессе, готово)
- Отслеживайте сколько порций добавлено в план, а сколько свободно

### 3. Планирование питания
- Составляйте сбалансированное меню на день
- Планируйте меню на недели вперед из своих запасов

## 🛠 Технологии

- **Flutter** - фреймворк для разработки кроссплатформенных приложений
- **Riverpod** - управление состоянием
- **Hive** - локальное хранение данных
- **Freezed** - генерация иммутабельных моделей
- **Flutter Hooks** - управление жизненным циклом виджетов

## 🏗 Архитектура проекта

```
lib/
├── core/                 # Базовые компоненты
│   ├── extensions/      # Расширения
│   └── hive_box_names.dart
├── models/              # Модели данных
│   ├── dish_template.dart    # Шаблоны блюд
│   ├── dish_stock.dart       # Заготовки
│   └── daily_meal_plan.dart  # План питания
├── providers/           # Управление состоянием
│   ├── dish_template/   # Работа с шаблонами
│   ├── dish_stock/      # Управление заготовками
│   └── daily_plan/      # Планирование питания
└── screens/            # Экраны приложения
    ├── dish_template/   # Создание и редактирование шаблонов
    ├── dish_stock/      # Управление заготовками
    └── daily_plan/      # Планирование питания
```

### Ключевые сущности

1. **DishTemplate** - шаблон блюда
   - Название
   - Количество порций в рецепте

2. **DishStock** - заготовка блюда
   - Связь с шаблоном
   - Количество приготовленных порций
   - Статус (запланировано, в процессе, готово)

3. **DailyMealPlan** - план питания на день
   - Дата
   - Список блюд с количеством порций

## 🎨 Особенности реализации

### Чистая архитектура
- Разделение на слои (models, providers, screens)
- Использование репозиториев для работы с данными
- Четкое разделение ответственности

### Управление состоянием
```dart
@freezed
class DishTemplateState with _$DishTemplateState {
  const factory DishTemplateState.initial() = _Initial;
  const factory DishTemplateState.loading() = _Loading;
  const factory DishTemplateState.loaded(List<DishTemplate> templates) = _Loaded;
  const factory DishTemplateState.error(String message) = _Error;
}
```

### Локальное хранение
- Использование Hive для быстрого доступа к данным
- Структурированное хранение с типами
- Эффективная работа с большими наборами данных

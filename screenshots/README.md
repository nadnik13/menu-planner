# 📸 Скриншоты приложения

## Инструкции для добавления скриншотов

### Требуемые файлы:

1. **main_screen.png** - Главный экран со статистикой
   - Показать AppBar с количеством порций и планов
   - Показать BottomNavigationBar
   - Размер: желательно iPhone или Android стандартный

2. **dish_list.png** - Список блюд с поиском
   - Показать search bar
   - Показать несколько блюд с разными статусами
   - Показать цветовое кодирование (зеленый/красный/серый)

3. **plan_creation.png** - Создание плана питания
   - Показать форму добавления плана
   - Date picker или календарь
   - Список блюд для выбора

4. **stock_management.png** - Управление запасами
   - Показать список запасов
   - Dropdown для изменения статуса
   - Кнопки редактирования/удаления

### Рекомендации:

- **Формат:** PNG для лучшего качества
- **Размер:** Ширина ~300-400px для README
- **Качество:** Четкие, читаемые скриншоты
- **Содержание:** Показать реальные данные, не пустые экраны

### Как добавить:

1. Сделайте скриншоты на устройстве/эмуляторе
2. Сохраните файлы в эту папку с указанными именами
3. Скриншоты автоматически отобразятся в README.md

### Альтернатива:

Если скриншоты пока недоступны, можно временно закомментировать секцию в README.md до их добавления.
